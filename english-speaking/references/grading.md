# 口语批改约定（「批」时必读）

批改对象：网页提交的两遍作答（`first` / `second`）。输出三段式，段落名用【】包裹（网页靠它分段渲染），每段内用 `- ` 短行。整段文本会原样显示在网页该题下方，供考前复习，所以每条都要独立可读。

## 输出格式

```
【语音识别还原】            ← 仅当存在同音误差时输出此段
spend / send → sing；seeing → singing（同音误差，不属于你的错误，已按 sing 批改）

【点评】
- 优点先说（具体到句）
- 残留问题：引用原句 → 修改说法 → 一句中文说清为什么（语法/搭配/地道性归类）
- 与第一遍对比一句：哪些错第二遍自己消灭了（已内化）、哪些两遍都在（顽固，要专项练）

【你的润色版】
<基于学生自己的答案升级，保留其个人细节与正确的句式，只替换/修正问题处>

【亮点】
- <表达> — <中文注释，一句话为什么值得学>
```

## 批改原则

1. **以第二遍为准**。第一遍只用于对比诊断（内化 vs 顽固），不单独成段、不逐条展开——两遍之间没有 AI 参与，对第一遍的详细反馈是马后炮
2. **语音识别同音误差不是学生的错**：先还原（sing/see/spend/send/their/there 这类同音混淆、无标点断句、my I I 等口头自我修正），还原段放最前，让学生复习时不困惑。还原后的真实语言问题才批
3. **润色版是「他的答案的 Band 7」，不是题库范文的复读**：学生答案里的个人细节（karaoke machine、mum 收拾玩具）和已经用对的升级句式（so…that 从句）必须保留，只修错误处、替换平淡表达。学生的好句式原样保留进润色版并在【亮点】里点名，这比模板句更能建立信心
4. **优点先行且具体**：引用他的原句说好在哪里，不说空话
5. **每题指出的问题 ≤ 4 条**，按价值排序（顽固错误 > 高频搭配 > 时态单三 > 地道性微调）。口语评分宽容度高，别用书面语标准轰炸
6. **亮点 2-4 个**，优先从学生自己用对/接近用对的表达里挑，其次才是润色版新引入的
7. 该生已知顽固问题（源自写作批改记录，口语同样适用）：冠词 a/an、人称 your/their 漂移、中式直译——出现时务必点名
